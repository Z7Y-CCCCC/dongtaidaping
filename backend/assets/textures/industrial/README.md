# Industrial texture assets

The files in this directory are derived from the following Poly Haven CC0 assets:

- `blue_metal_plate` (1K): subtle paint roughness and normal detail used by the V5 furnace.
- `blocky_photo_studio` (1K HDR): neutral studio lighting reference used for Blender previews and runtime image-based lighting.

Poly Haven assets are released under CC0 and may be used in commercial deployments. Source: <https://polyhaven.com/license>
